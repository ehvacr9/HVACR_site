Moody 圖

    Re < 2300 為層流區，Re > 4000 為紊流區，兩者之間為過渡區。為呈現曲線走勢，紊流參考線依 Colebrook 式向左延伸至 Re = 2000；Re < 4000 的延伸部分僅供圖形參考，不代表該區為紊流。

    計算方法與適用範圍

    以 Re = ρvD / μ 計算雷諾數，並以相對粗糙度 ε / D 取得 Moody 摩擦因子；其中 ρ 為流體密度、v 為平均流速、D 為管內徑、μ 為動力（絕對）黏度，ε 為管壁絕對粗糙度。

    層流摩擦因子採 f = 64 / Re；紊流以 Colebrook–White 式計算：1 / √f = −2 log₁₀[(ε / D) / 3.7 + 2.51 / (Re √f)]。

    Re < 2,300 為層流區，Re > 4,000 為紊流區；Re = 2,300–4,000 為過渡區，摩擦因子以層流端與 Re = 4,000 的紊流值線性估算，此區流況不穩定，結果僅供參考。圖中紊流曲線雖向左延伸至 Re = 2,000，但該延伸僅供曲線視覺參考，計算仍採過渡區估算。f 為 Darcy 摩擦因子，非 Fanning 摩擦因子。
