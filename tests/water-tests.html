Water calculation regression tests

Open this page in a browser. Tests run locally using the same modules as PyCool.

Numerical checks: IAPWS-95 (2018) Tables 7–8; IAPWS viscosity (2008) Table 4; IAPWS R14-08(2011) Table 3 for internal solid-region validation; valid domains, quality mixing and temperature/pressure round trips.

Integration checks run the real PyCool page in a temporary same-origin iframe: displayed units, supported/unsupported property pairs, range rejection (including solid water), vapor-liquid tables and CSV, integer defaults for all fluids, removal of solid-line controls and Ph charts, including drawing loading/error states and all 17 fluids' chart limits, curve coordinates, label collisions, pointer readouts and color/monochrome PNG exports; R410A/R407C bubble/dew points, temperature glide, P-T/T-Q states and constant-temperature/pressure quality tables. Serve the site over HTTP and open this page; no package installation is required.
