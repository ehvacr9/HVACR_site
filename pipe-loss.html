計算方法與適用範圍

本頁提供 16 種元件的局部損失估算；左側按流動特性分組，不代表全部採用同一個 ASHRAE 查表模型。以下逐項說明係數來源、流速基準與使用限制。

元件核對與使用條件（K 為無因次係數）
元件係數／來源流速基準幾何與使用限制
突縮K ≈ 0.5(1 − r)，銳邊近似下游小管 V₂同軸突然收縮；不是漸縮管或圓角縮口模型。
突擴K = (1 − r)²，Borda–Carnot上游小管 V₁同軸突然擴張；損失壓力當量不等於兩端靜壓差。

90° 長半徑彎頭ASHRAE 表 3，DN 20–100管內平均流速長半徑螺紋型式；R/D = 1.5 僅為圖面幾何示意，不是任意曲率的 K 公式。

球形閥（Globe）ASHRAE 表 3，DN 10–100管內平均流速全開球形／截止閥；不是球閥（Ball），不可用來估算節流開度。
閘閥（Gate）ASHRAE 表 3，DN 10–100管內平均流速閘板完全上提；半開閘閥不適用。
角閥（Angle）ASHRAE 表 3，DN 20–100管內平均流速全開角型截止閥，兩管口相差 90°；不是一般彎頭或任意衛浴角閥。
旋啟式止回閥ASHRAE 表 3，DN 10–100順向管內平均流速順流啟開；不模擬逆流關閉、啟開壓差或閥瓣部分開啟。

方口入口ASHRAE 表 3，K = 0.5下游管內流速圓管銳邊平口與槽壁齊平；「方口」不是方形管截面。
突出管口入口ASHRAE 表 3，K = 1下游管內流速管口伸入槽內；伸入長度、壁厚及口緣形狀不同時須另查資料。
出口・大型槽體K = 1，速度水頭耗散模型上游出口管內流速排入平均流速可忽略的大槽；不適用於自由射流出口或帶擴散器的出口。

突擴：Borda–Carnot 關係式

r = A₁/A₂ = (D₁/D₂)²；K = (1 − r)²；Vref = V₁

由等截面入口與出口的連續、動量及能量平衡，假設分離區壓力近似上游壓力，可得 hL = (V₁ − V₂)²/(2g)。以小管的上游流速表示後即為上述 K。

突縮：銳邊工程近似

r = A₂/A₁ = (D₂/D₁)²；K ≈ 0.5(1 − r)；Vref = V₂

突然收縮形成縮流斷面（vena contracta），主要損失來自縮流後的混合與再擴張。若縮流係數 Cc = Ac/A₂，模型為 K = (1/Cc − 1)²；但 Cc 受幾何及流況影響，不能單靠守恆方程式唯一決定。本工具採常用的銳邊簡化近似 K ≈ 0.5(1 − r)，不是精確理論解，也不是圖片曲線的擬合。r → 0 時 K → 0.5；r = 1 時 K = 0。

水頭與壓力損失

A = πD²/4；V = Q/A；hL = K Vref²/(2g)；ΔpL = ρg hL

使用 g = 9.80665 m/s²，輸入流量換為 m³/s 後計算。突縮／突擴的 K 依前述小管流速定義；標準管件 K 以管內平均流速為基準。K 的速度基準須與其定義一致。

標準管件 K 值

ASHRAE Handbook—Fundamentals 2025，第 22 章表 3列有螺紋鋼管彎頭、回彎、等徑三通、閥件及入口的係數。本工具提供表列型式及 DN 10–100 的離散值（鐘口、方口及突出管口入口依表列係數，不隨管徑變化）；表 3 資料來源註記為 Hydraulic Institute《Engineering Data Book》(1990)。表 5 亦提醒不同產品間係數可能有明顯差異；未提供的尺寸或型式不進行插值。

球形閥、閘閥及角閥按全開條件使用；旋啟式止回閥按順向啟開條件估算。閥門開度、內部結構及產品設計不同時，壓損可能顯著不同，應優先採製造商 Cv/Kv 或壓損曲線。球形閥（Globe valve）不是球閥（Ball valve）。

目前三通選項僅提供分流／合流的上限估算，不使用表 3 的 Tee-Line／Tee-Branch 固定係數。排入大型槽體以出口速度水頭全部耗散計 K = 1；這是能量平衡模型，不是表 3 的入口數值。

鋼管 Schedule 40／80 的內徑參考同章表 16；亦可選自訂內徑。K 仍按公稱管徑選取，流速依實際內徑計算。內徑受製造公差、腐蝕及結垢影響，正式計算請核對實際管材。

參考值供初步估算，流況、製造差異及相鄰管件均可能影響損失；未輸入黏度，無法判斷雷諾數。正式設計請採實際管件製造商資料並確認適用流況。

等徑三通：保守上限估算

依 ASHRAE Handbook—Fundamentals 2025，第 22 章 Tee Fitting Pressure Drop 的上限估算，以進口與出口速度水頭之和估算各路徑損失：hL ≈ (Vin² + Vout²)/(2g)。此為估算而非實測值，也不能保證涵蓋所有管件與工況。

假設三管口等內徑，令 x = Q支/Q，並以共同管口流速 V共 為基準，直通路徑 K ≈ 1 + (1 − x)²；支管路徑 K ≈ 1 + x²。分流和合流分別按共同管口與各支路的進、出口速度代入；無流量路徑不報告損失。流量為零時比例沒有物理意義，故不顯示路徑係數與損失。

圖面與模型核對

圖面為流路與內部構件示意，不是製造圖：45° 與 90° 彎頭採同心圓弧維持等寬流道；等徑三通三個管口等寬，箭頭按分流／合流標示；回彎箭頭對齊中心線；閘閥閘板上提至流道之外；角閥保留閥蓋與垂直閥桿；球形閥與角閥的閥座保留開口；旋啟式止回閥顯示向下游掀開的閥瓣；鐘口平滑銜接，槽體圖採一致的管口寬度。管件曲率、閥瓣升程及槽體大小未作為計算輸入，不能由圖面讀取額外係數。深灰線為固定邊界與閥座，琥珀線為活動構件，藍綠箭頭為流向。

共同適用範圍

用於穩態、單相、近似不可壓縮流體的局部損失初估；表列 K 與近似式須符合各元件的幾何、開度及流況假設。充分紊流時固定 K 通常較適用，但本工具未輸入黏度，不自動判斷雷諾數。不包含直管摩擦、相鄰管件交互影響、兩相流、明顯可壓縮、汽蝕及水錘；不可用於任意漸縮／漸擴或任意閥門開度。零流量可查固定 K，但無流量三通路徑不報告係數與損失。正式設計請使用製造商或相符試驗資料。
